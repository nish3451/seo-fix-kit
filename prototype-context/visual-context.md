# Visual Context

## Direction

Quiet, operational SaaS interface. No marketing hero. The first screen should feel like a working audit desk.

## Product feeling

- Trustworthy.
- Dense but readable.
- Evidence-first.
- Less "SEO wizard", more "technical repair report".

## Layout

- Left side: URL input, audit summary, scan scope.
- Right side: verified findings and fix snippets.
- Strong distinction between verified issues, guarded false positives, and optional enhancements.

## Visual references

- Browser DevTools clarity.
- Linear issue triage density.
- Search Console-like restraint.
