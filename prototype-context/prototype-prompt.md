# Build Prompt

Build a local SaaS MVP called Proof SEO.

The product promise is: "Tell me what is wrong with my site, prove it, and generate the fix."

Use a rendered browser crawl before judging page content. Compare static HTML and rendered DOM so the report can flag when a static-only crawler would be wrong. Every issue must include evidence, confidence, and a suggested fix. The UI should be a real working audit surface, not a landing page.
