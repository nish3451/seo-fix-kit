# Decision Context

## Prototype decision

Can we make a better SEOitis-style tool by focusing on verified SEO repair instead of a generic score?

## What this version proves

- It can render a page like a browser before judging SEO issues.
- It can show proof for every finding.
- It can avoid common false positives from static-only crawlers.
- It can generate exact patches a founder or vibecoder can apply.

## What this version does not prove yet

- It does not replace Ahrefs or Semrush keyword and backlink databases.
- It does not yet run scheduled monitoring.
- It does not yet include billing, accounts, team workspaces, or agency exports.
